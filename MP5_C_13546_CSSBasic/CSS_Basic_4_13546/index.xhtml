Penggunaan Tiga Jenis CSS

Halaman latihan ini menggabungkan Inline Style Sheet, Embedded Style Sheet, dan Linked Style Sheet dalam satu dokumen XHTML.

1. Inline Style Sheet

CSS ditulis langsung pada atribut style di elemen XHTML.

2. Embedded Style Sheet

CSS ditulis di dalam elemen style pada bagian head.

3. Linked Style Sheet

CSS ditulis pada file terpisah, yaitu style.css, lalu dihubungkan ke dokumen XHTML.
